# Tools

Calculators and planners that go with these guides.

## Raised-bed calculator

The first tool. Describe one or more rectangular raised beds built from stacked 2x boards (size, board, height, treatment, corner posts, soil) and it works out the cut list, which boards to buy and how to cut them, the screws, the soil and the total cost. Beds on one list share offcuts.

The prices are placeholders, not a store's current prices, and the cut plans allow nothing for the saw blade. The calculator is not published on this site yet: to try it, run it from the repository (see the [README](https://github.com/Chris-Wolfgang/Gardening#raised-bed-calculator)).
